#Online Bookstore

	##Project Description:

 	An online bookstore website that allows users to explore books, 
	browse different categories, 
	view book details, and manage their shopping cart.

	##Features:			
		
	-Home page
	-About page
	-Book categories
	-Book details
	-Shopping cart
	-Add and remove books
	-Total price calculation
	-Login and Sign Up interfaces
	-Responsive design
